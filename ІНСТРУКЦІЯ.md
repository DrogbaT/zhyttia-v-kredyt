# Життя в кредит — Android-застосунок

Гра на одному телефоні працює офлайн; онлайн-режим потребує інтернету. Без реклами.
Сама гра лежить у `app/src/main/assets/index.html` — якщо міняєш гру, міняй цей файл.

## 1. Зібрати і перевірити на телефоні

1. Встанови **Android Studio** (безкоштовно): https://developer.android.com/studio
2. `File → Open` → вибери папку `ZhyttiaVKredyt`. Зачекай, поки Gradle все завантажить
   (перший раз 5–10 хвилин). Якщо запропонує оновити Android Gradle Plugin — погоджуйся.
3. На телефоні увімкни «Режим розробника» і «Налагодження USB», підключи кабелем.
4. Натисни зелену кнопку ▶ **Run** — гра встановиться на телефон як окремий застосунок.

Просто APK, щоб скинути другу: `Build → Build App Bundle(s) / APK(s) → Build APK(s)`.

## 2. Перед публікацією

- **ID застосунку** у `app/build.gradle.kts` → `applicationId = "com.lifeincredit.game"`.
  Заміни на свій унікальний (наприклад `com.твійнік.lifeincredit`). Після першого
  завантаження в Play змінити його вже не можна. `namespace` можна не чіпати.
- Перед кожним оновленням збільшуй `versionCode` на 1.

## 3. Зробити файл для Google Play (.aab)

1. `Build → Generate Signed App Bundle / APK…` → **Android App Bundle**.
2. `Create new…` — створи ключ (keystore). **Збережи файл .jks і паролі в надійному місці** —
   без них не зможеш випускати оновлення.
3. Вибери `release` → Finish. Файл буде тут: `app/release/app-release.aab`.

## 4. Google Play Console

1. Акаунт розробника: https://play.google.com/console — разовий внесок 25 $ і перевірка особи.
2. **Новий особистий акаунт:** спочатку закрите тестування — щонайменше **12 тестерів**
   мають бути в тесті **14 днів поспіль**. Тільки після цього відкриється публікація для всіх.
3. Створи застосунок, завантаж `.aab` у трек закритого тестування, додай пошти тестерів.
4. Заповни сторінку в магазині — в папці `play-store` вже є:
   - `icon-512.png` — іконка 512×512
   - `feature-graphic-1024x500.png` — банер
   - Скріншоти (мінімум 2) зроби з телефону сам.
5. **Політика конфіденційності** — потрібне посилання. Текст у `play-store/privacy-policy.md`:
   опублікуй його безкоштовно (Google Sites, GitHub Pages чи Notion) і встав посилання.
6. Анкета «Безпека даних» (Data safety): ти нічого не збираєш на свої сервери. В онлайн-режимі нікнейм передається іншим гравцям у кімнаті напряму — опиши це чесно (див. політику конфіденційності).
7. Вікова анкета: в грі є азарт без справжніх грошей (кубики) і згадки про вечірки — відповідай чесно.

## Технічне

- minSdk 26 (Android 8+), targetSdk 36 (вимога Google Play з 31.08.2026).
- Інтернет потрібен лише для онлайн-режиму (сервер-посередник PeerJS + WebRTC). Профіль і збереження — у пам’яті застосунку.
- Поворот екрана: авто, або зафіксувати в налаштуваннях гри.
