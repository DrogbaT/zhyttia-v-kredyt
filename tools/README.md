# Інструменти

- `game-source-uk.html` — вихідний код гри (українською). Тут правиться гра.
- `i18n/conv.py` — обгортає всі українські фрази у `T(...)` і створює `keys.json`.
- `i18n/<мова>.txt` — переклади у форматі `номер§текст` (номери з `keys.txt`).
- `i18n/check.py <мова>` — перевіряє переклад (плейсхолдери, теги) і робить `tr_<мова>.json`.

Мови: українська (оригінал), English, Deutsch, Polski, Español, Français, Italiano, Português, Türkçe.
